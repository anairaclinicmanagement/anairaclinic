# Anaira Clinic Pharmacy v1.0.6 — Walk-in Customers

- Added a pharmacy-counter form to create/select an outside walk-in customer while dispensing/billing.
- The customer is saved in the selected clinic's `patients` table through a protected RPC; UHID is generated by the existing database trigger.
- Does not create an OPD visit, appointment, encounter, or prescription.
- Optional fields: last name, phone, gender, DOB, address. Name is required.
- Scope: authenticated owner/admin/pharmacist, selected clinic membership and Pharmacy module entitlement required.
- Dispensing continues to use `dispense_pharmacy_sale`, which validates that patient belongs to the same clinic, and applies existing stock/expiry/prescription rules.
- Migration `20261025142000_pharmacy_walkin_customer_creation.sql` applied to the linked Anaira Clinic Supabase project. Address persistence fix also applied.
