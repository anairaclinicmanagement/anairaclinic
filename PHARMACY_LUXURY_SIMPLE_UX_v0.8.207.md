# Pharmacy Premium UX — v0.8.207

## Design goals
- Simple, task-first navigation with seven clearly named areas: Dispensing & Bills, Medicines & Stock, Purchases, OPD Prescriptions, Reports, Suppliers and Settings.
- Anaira emerald + champagne-gold luxury visual language, readable typography, clear active navigation, consistent panels, forms, tables and actions.
- Compact pharmacy-at-a-glance metrics for medicine items, units in stock, low/expiry alerts and batches.
- Responsive navigation and metrics for mobile and desktop.
- Existing pharmacy workflows, Supabase calls, clinic scoping, billing, GRN and OCR logic are retained.

## Scope
This release is a presentation and navigation usability pass. It does not change pharmacy database schema or stock/accounting business rules.
